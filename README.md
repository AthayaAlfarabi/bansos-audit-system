# Sistem Rekomendasi Prioritas Audit Penyaluran Bantuan Sosial

## Deskripsi
Proyek ini mengembangkan sistem rekomendasi prioritas audit untuk penyaluran bantuan sosial di Jawa Timur menggunakan pendekatan Hybrid Machine Learning yang menggabungkan Rule-Based, Statistical, dan Spatial analysis.

## Fitur Utama
- ✅ Deteksi anomali berbasis Hybrid Machine Learning
- ✅ Analisis signature fraud patterns
- ✅ Sistem rekomendasi prioritas audit
- ✅ Dashboard interaktif dengan Streamlit
- ✅ Optimasi threshold berbasis expected cost
